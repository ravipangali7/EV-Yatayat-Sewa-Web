# EV Yatayat Sewa (web)

Frontend for EV Yatayat Sewa — Vite + React + TypeScript + Tailwind + shadcn-ui.

## Local development

Requires Node.js and npm.

```sh
npm i
npm run dev
```

Dev server defaults to port `8080`.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint |
| `npm test` | Vitest |
